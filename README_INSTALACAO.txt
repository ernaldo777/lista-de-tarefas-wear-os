ARQUIVOS DO TRABALHO PRÁTICO - ListaDeTarefas Wear OS

Objetivo:
Estes arquivos criam um app simples para Wear OS que verifica saídas de áudio do dispositivo,
identifica alto-falante interno, verifica fone Bluetooth e permite abrir as configurações de Bluetooth.

Como usar no Android Studio:

1. Copie o conteúdo da pasta "app" deste pacote para dentro da pasta "app" do seu projeto ListaDeTarefas.

2. Os arquivos devem ficar nos seguintes caminhos:

   app/src/main/java/com/example/listadetarefas/MainActivity.java
   app/src/main/res/layout/activity_main.xml
   app/src/main/AndroidManifest.xml
   app/src/main/res/values/themes.xml
   app/src/main/res/values/strings.xml

3. No Android Studio, clique em:

   File > Sync Project with Gradle Files

4. Depois crie ou selecione um emulador Wear OS:

   Tools > Device Manager > Create Device > Wear OS

5. Execute o app clicando em Run.

6. Prints sugeridos para a documentação:

   - Projeto aberto no Android Studio;
   - AndroidManifest.xml com permissões;
   - MainActivity.java com a lógica de áudio;
   - Emulador Wear OS configurado;
   - App rodando no emulador.
